# Digitraffic Marine - Voyage plan gateway

This used to be an STM VIS private side module. See
[https://www.seatrafficmanagement.info/developers-forum/vis/](https://www.seatrafficmanagement.info/developers-forum/vis/)
for details.

The remaining schedules public API still serves VTS schedules.

## Retention notice

This project must be kept even though most of the original STM VIS functionality was removed -
do not remove it. The remaining VTS schedules API (`/temp/schedules`) is required to stay
available due to the EU mandatory retention requirement, so it cannot be decommissioned without
a separate, explicit decision.
