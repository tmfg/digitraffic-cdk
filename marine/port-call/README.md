# Portcall activity CDK project

Set up the local marine database first. The database Docker setup and Flyway
migrations are in the [digitraffic-marine](https://github.com/tmfg/digitraffic-marine)
repository under `dbmarine/`. See `dbmarine/README.md` there for instructions.

- Run tests with `rushx test`
- Compile in watch mode with `rushx build:watch`
