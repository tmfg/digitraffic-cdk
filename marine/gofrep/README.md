# Digitraffic Marine - GOFREP

GOFREP (Gulf of Finland Reporting) is the mandatory ship reporting system for the Gulf of Finland.
This project implements the MRS (Mandatory Reporting System) integration API used by ship reporting
clients to fetch formality/reporting-obligation metadata (`/mrs/formality`) and to submit ISO 28005
EPC report messages (`/mrs/report`).

## Retention notice

This project must be kept even though it looks unused/legacy - do not remove it. The EU mandatory
ship reporting regulation requires this integration to remain available, so GOFREP cannot be
decommissioned without a separate, explicit decision.
